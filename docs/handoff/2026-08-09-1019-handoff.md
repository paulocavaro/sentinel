## What Sentinel is

A daily edition of AI and world news. A scheduled job reads eighteen sources,
a model picks and ranks up to thirty items across five themes, and the result is
committed to this repository as a dated JSON file. The site is static; the git
history is the archive. Read [`docs/spec.md`](../spec.md) — it is current and it
is the product's own source of truth.

Live: the Vercel project `paulo-dev3/sentinel`, deployed from `main`.

## Decisions that would be expensive to relitigate

Each of these was argued, measured, or paid for once. The reasoning lives in the
commit messages and in the code comments beside the decision; the commits are
unusually detailed on purpose.

- **The rank numeral is not shown.** It orders the edition and nothing else.
- **No right rail.** Every rail in ten measured newspapers carries a second
  content type or a second sort of a larger corpus; this product has one type,
  one sort, and it fits on the page.
- **Tailwind was removed.** `app/globals.css` and the design references are
  deliberately the same document in two places — that identity is what makes the
  visual gate worth running.
- **No icon set, no shadow scale, no radius scale, no colour-coded themes, no
  density toggle, no `Card`.** All refused in writing in
  [`docs/design-system.md`](../design-system.md), with reasons.
- **Themes are weighted by slot count, not by a multiplier.** A multiplier on a
  linear merit ramp demotes a theme's best items and leaves its worst alone.
- **An edition is never rewritten.** The 8 August edition predates themes and
  must not be backfilled; the reader tolerates its shape.

## Repository conventions worth knowing before touching anything

- **Gate order is fixed**: build → typecheck → lint → test. Next 16 generates
  route types during build and `tsc` fails without them.
- **Read `node_modules/next/dist/docs/` before writing anything Next-specific.**
  Three silent failures in this phase came from recalled APIs being wrong for 16.
- **Design references are generated, never hand-edited.** See
  [`design-refs/README.md`](../../design-refs/README.md) for the regeneration
  order — `build-states.mjs` lifts its stylesheet from `home.html`, so it runs
  last.
- **Commits are atomic per task and explain why, not what.** Push, merge and PR
  are always the human's call.
- **This repository is public and must never mention the selection process it was
  built for.** That context lives in the user's Obsidian vault, at
  `Side Projects/Sentinel/`.
